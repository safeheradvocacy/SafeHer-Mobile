Layer Technology Role in SafeSpace

Web Admin Portal		 React 18.3.1 + Vite 5.4.5 Component framework and build tool for the administrative dashboard.
TypeScript Type-safe application code across every admin page and library.
React Router DOM Page routing across case management, shelters, personnel, and reports.
Chart.js (react-chartjs-2), Lucide React Analytics/report charts and interface iconography.
Application &
Business Logic		 Supabase Edge Functions (Deno) Server-side logic requiring elevated privilege: account creation, backup/restore, the support chatbot, security-passcode verification, and push-notification dispatch.
PostgreSQL Row-Level Security (RLS) Enforces each of the eight roles' authorized data scope directly at the database level — the real authorization boundary, not just the interface.
PostgreSQL Functions & Triggers Server-side business rules: automatic case numbering, audit-log capture, and account provisioning on signup.
Data Supabase-managed PostgreSQL Primary relational database for every case, user, shelter, and SOS record.
Supabase Storage File storage for incident evidence, identity-verification documents, profile photos, shelter photos, and system backups.
Authentication &
Security		 Supabase Auth Email/password authentication and session management for both applications.
Security Passcode (bcrypt via pgcrypto) A second, mobile-only credential gating access to submitted case details.
Biometric Lock (expo-local-authentication) Device-level fingerprint/face lock for the mobile app.
Real-Time
Communication		 Supabase Realtime Live delivery of Emergency SOS alerts to the police dashboard and live in-app notification updates.
External
Integrations		 PSGC (Philippine Statistics Authority) Official municipality and barangay reference data for Aurora Province.
Expo Push Notification Service Delivers push notifications to registered mobile devices.
Google Maps Platform Map rendering and geolocation display on mobile.
Hosting &
Deployment		 Vercel Hosts and deploys the web admin portal.
Expo Application Services (EAS) Builds and distributes the mobile application.

Both applications communicate with the backend through @supabase/supabase-js — REST (PostgREST) for queries/writes and a WebSocket channel for Realtime subscriptions.
