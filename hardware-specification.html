System Requirements

Hardware Specification

Specifications reflect the actual hardware needed to develop, operate, and access SafeSpace across its three real surfaces: the React Native/Expo mobile app, the React/Vite web admin portal, and the Supabase managed cloud backend. The backend is cloud-hosted infrastructure, not on-premise server hardware — PSWDO Aurora does not need to purchase or maintain a physical server.
