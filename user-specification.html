System Requirements

User Specification

Scope reflects each role's real jurisdiction boundary as enforced by the system's access-control rules (row-level security), not just a title — e.g. a Barangay Administrator's access is confined to their own barangay, and a Shelter Administrator's to their own shelter, regardless of what they can see in the interface.

Table 4

User Specification

User Category Platform Scope Description and Authorized Responsibilities
Survivor / Reporter Mobile Application Individual — own account only Submits incident reports with supporting evidence, tracks the status and history of their own case, requests shelter assistance, triggers Emergency SOS with real-time location sharing, and manages their own profile and emergency contact information.
Barangay Administrator Web Administration Dashboard Barangay — assigned barangay only Reviews and acts on barangay-level action requests (e.g., Barangay Protection Orders) and monitors cases routed to the barangay, within the assigned barangay's jurisdiction.
Municipal Administrator (MSWDO) Web Administration Dashboard Municipality — assigned municipality only Oversees case management and shelter referrals for the assigned municipality, coordinates with barangay and shelter partners, creates and manages municipal- and barangay-level accounts, and generates municipal-level reports.
Provincial Admin (Super Administrator) Web Administration Dashboard Province-wide Administers the system province-wide: creates and manages every account type and role, maintains municipality, barangay, and shelter reference data, configures system-wide settings, and oversees audit logs and data backup/restore.
Provincial Staff Web Administration Dashboard Province-wide — operational, no jurisdiction assignment Supports provincial-level case monitoring, coordination, and reporting activities without full administrative privileges.
Shelter Administrator Web Administration Dashboard Own shelter only Maintains their shelter's listing and photos, reviews and responds to incoming shelter requests, and manages case-to-shelter referrals directed to their shelter.
Support Expert Web Administration Dashboard Assigned requests only — no jurisdiction assignment Responds to confidential support requests assigned to them through the system's support queue.
Police Officer (Law Enforcement) Web Administration Dashboard Assigned SOS alerts and referrals Monitors and responds to Emergency SOS alerts routed to law enforcement, and acts on law-enforcement case referrals within their authorized response role.

All eight roles are enforced server-side; a user cannot read or act outside their listed scope regardless of what the client interface requests.
